# 精度验证核对清单

## 通用前置清单

- [ ] 已检查官方 README / 文档 / benchmark 是否给出基线
- [ ] 基线来源已确认（官方 / 用户 GPU / 仅调试）
- [ ] 如做了 CPU 对比，已明确标注用途
- [ ] 阈值已在比较前声明
- [ ] 确定性条件已设置（随机性关闭、JIT 禁用等）

## 训练精度对齐

- [ ] 两侧代码版本一致
- [ ] 使用同一 checkpoint 或初始化方式
- [ ] 数据集内容和顺序一致
- [ ] seed 和随机性控制一致
- [ ] batch size 与梯度累积一致
- [ ] 优化器、scheduler、warmup 一致
- [ ] loss 函数和 reduction 模式一致
- [ ] 精度模式与 autocast 边界一致
- [ ] 分布式 world size 和 reduction 语义一致

## 推理精度对齐

- [ ] checkpoint 和权重转换路径一致
- [ ] 预处理流程一致（tokenizer、归一化、resize、padding）
- [ ] 解码/后处理参数一致（temperature、top_k、beam_size 等）
- [ ] 样本集及顺序一致
- [ ] batch shape 与动态 shape 行为一致

## 结论输出清单

- [ ] 明确说明是否对齐
- [ ] 明确说明基线来源
- [ ] 明确说明比较覆盖范围
- [ ] 明确说明使用的阈值及其依据
- [ ] 明确区分“已证实结论”和“合理推测”
- [ ] 如只覆盖示例级，未写成“模型已完成精度对齐”
- [ ] 如只做 CPU 对比，未写成正式对齐结论
