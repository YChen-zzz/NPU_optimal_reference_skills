# NPU 融合算子参考

## 查询流程

1. **先查表**：打开 [npu_operator_catalog.yaml](npu_operator_catalog.yaml)，搜索模型中的计算模式是否已有对应的融合算子
2. **表里没有再查库**：运行 `[x for x in dir(torch_npu) if 'npu_' in x.lower()]` 发现可用算子，然后查昇腾官方 API 文档（搜索方式：`site:hiascend.com torch_npu <算子名>`）获取 dtype/constraint
3. **查完更新表**：将新发现的算子信息追加到 YAML 目录中，避免重复查询

## 通用注意事项

- **查看签名**：故意传错参数触发报错，报错信息会打印完整 schema
- **Probe 必须加 synchronize**：NPU 异步执行，`try/except` 内不加 `torch.npu.synchronize()` 无法捕获错误
- **返回值数量不固定**：多数融合算子返回多个值，用 `result, *_ =` 解包更安全
